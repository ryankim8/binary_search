You will implement several variations of the binary search algorithm.
These algorithms are often also called "divide and conquer" algorithms,
and they are very popular because of their fast runtimes.

**Learning Objectives:**

1. understand the binary search algorithm
1. practice recursion

## Tasks

Complete the following tasks:

1. Fork the repo and enable github actions
1. Update the `README.md` file so that the test case badges point to your forked repo
1. Implement the functions so that all test cases pass.
